七、核心安全保障清单

#安全项机制状态
1许可泄漏防护redispatch 先 release 再改 DB；release 对未持有许可的实例幂等 no-op✓
2全局级幂等保护Local: globalPermits.add() / Redis: Lua SISMEMBER✓
3Worker级幂等保护Local: putIfAbsent / Redis: Lua GET KEYS[2]✓
4Worker计数器缩容remaining==0 时 compute 条件删除✓
5Redis恢复多节点竞态分布式锁 + check-and-delete 释放锁✓
6Redis恢复完整重建permits + inst:worker + workerCount 全部重建✓
7Redis Key TTL兜底pj:cl:inst:*:worker 带 SET EX TTL，崩溃后自动过期✓
8QUEUE回调语义回调仅在 REJECT/超时降级时发送，QUEUE排队不发回调✓
9QUEUE超时降级maxQueueWaitMs + isQueueTimeout → 降级为REJECT✓
10Fail-Open降级Redis故障时放行而非阻，避免级联故障✓
11零侵入可选@Autowired(required=false) + @ConditionalOnProperty✓
12release幂等安全Local: remove返回false不减 / Redis: SREM==0不DECR✓

八、配置项参考

配置项默认值说明
powerjob.server.concurrency.enabledfalse是否启用全局并发限制
powerjob.server.concurrency.max-global-concurrency1000全局最大并发任务数
powerjob.server.concurrency.max-worker-concurrency100单 Worker 最大并发任务数（0=不限制）
powerjob.server.concurrency.over-limit-policyREJECT超限策略：REJECT 直接失败 / QUEUE 排队等待
powerjob.server.concurrency.max-queue-wait-ms60000QUEUE 策略最长等待时间（ms），-1 不限制
powerjob.server.concurrency.inst-worker-key-ttl-seconds86400Redis inst:worker 映射 Key TTL（秒）
powerjob.server.concurrency.limiter-typelocal限制器类型：local / redis
